Kéo thanh cuộn Chuẩn con lăn Windows

Danh Sách Ứng Dụng Loại Trừ (Exclusion List)

Thêm phần mềm đồ họa (Photoshop, CAD, Blender) hoặc game FPS (Valorant, CS:GO). GestureMouse tự động bỏ qua để giữ nguyên 100% chuột phải gốc.

Khởi Chạy Cùng Windows & UIAccess

Tự khởi động cùng hệ thống và tích hợp UIAccess để điều khiển Task Manager và các cửa sổ Administrator mà không bị UAC chặn.

⚡ Bộ Phím Tắt Năng Suất Tích Hợp

Thao tác tức thời với các phím tắt hệ thống được thiết kế tối ưu

Ctrl + Shift + L

Hẹn Giờ Khóa Màn Hình

Mở hộp thoại đếm ngược số phút để tự động khóa máy (Lock Workstation) khi rời máy tính.

Ctrl + Shift + M

Tắt/Bật Âm Thanh Tức Thì

Ngắt tiếng (Mute) hoặc bật lại âm thanh hệ thống ngay lập tức, cực kỳ hữu dụng trong họp hoặc nghe gọi.

Win + Lăn chuột

Tăng/Giảm Âm Lượng

Giữ phím Windows kết hợp xoay con lăn chuột lên hoặc xuống để thay đổi âm lượng nhanh ở mọi vị trí.

Ctrl + Alt + L

Khóa Chuột & Bàn Phím

Khóa an toàn khi lau chùi bụi bẩn hoặc tránh trẻ em nghịch bấm linh tinh. Gõ từ khóa unlock để mở khóa.

Ctrl + Shift + V

Dán Văn Bản Thuần

Tự động loại bỏ toàn bộ định dạng font chữ, màu sắc và cắt tỉa khoảng trắng thừa trước khi dán.

F9 / F10

Độ Sáng Màn Hình

Tăng giảm trực tiếp độ sáng màn hình dịu mắt vào ban đêm mà không cần bấm phím cứng màn hình.

Bắt Đầu Dùng Thử Sau 10 Giây

Không cần cài đặt phức tạp, không rác hệ thống

1

Tải file .exe

Tải bản phát hành mới nhất từ GitHub Releases hoặc dùng lệnh winget install GestureMouse.

2

Mở & Trải nghiệm

Nhấp đúp chuột vào file GestureMouse.exe để bắt đầu sử dụng ngay lập tức.

3

Cài đặt UIAccess

Nhấp chuột phải vào icon ở khay hệ thống, chọn Cài đặt vào hệ thống để mở khóa mọi tính năng nâng cao và tự khởi động.
